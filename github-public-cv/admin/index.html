Đăng nhập bằng quyền GitHub

Dùng mã truy cập GitHub giới hạn cho repository Profile-CV. Đây không phải mật khẩu tài khoản GitHub.

Mã chỉ tồn tại trong bộ nhớ của tab này, không lưu vào bản nháp hay mã website. Phiên kết thúc sau 20 phút không hoạt động.

Cách lấy quyền truy cập
  1. Mở trang tạo fine-grained token, chọn chủ sở hữu LeTPhu.
  2. Chỉ chọn repository Profile-CV. Đặt thời hạn ngắn, ví dụ 7 ngày.
  3. Repository permissions: Contents → Read and write; Metadata → Read-only. Không cần quyền Workflow.
  4. Tạo mã, nhập vào ô trên. Không chia sẻ mã này cho người khác.
