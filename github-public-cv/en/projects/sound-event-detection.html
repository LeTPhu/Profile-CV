Sound Event Detection.

Audio event detection research

A study of audio event detection models comparing experimental inference with published benchmarks.

Academic project - NTTU

01 / Project overview

Scope & contributions

  • Studied Log-Mel, CRNN, DESED/DCASE and ATST-SED, comparing experimental inference with published benchmarks.
  • Experimented with CNN-Transformer/ATST-SED on Google Colab and read onset/offset event timelines.
  • Compared CRNN+BEATs, AST-SED and PaSST; explored CLAP/open-vocabulary as a possible extension.
  • Separated self-run results from reference figures in papers and repositories.
